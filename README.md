# education-website

好奇號自然教室：給國小學生的互動自然科學網站（繁體中文）。

純 HTML / CSS / JavaScript，不需要安裝或編譯，直接用瀏覽器打開 `index.html` 即可，也可以放到 GitHub Pages。

## 主題

| 主題 | 檔案 | 內容 |
| --- | --- | --- |
| 為什麼會有春夏秋冬？ | `topics/four-seasons.html` | 地球公轉與地軸傾斜、直射與斜射、熱帶／副熱帶／溫帶／極區、世界各地的太陽高度與白天長度、小測驗 |

## 新增主題

在 `topics/` 新增一個獨立的 HTML 檔，並在 `index.html` 的卡片列表加上連結。
